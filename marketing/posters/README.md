## 🖨️ How to Preview, Export & Print

1. **Viewing in Browser:**
   - Double-click any of the `.html` files or open them in Chrome, Edge, or Firefox.
   - For example: `file:///E:/EmbeddedSystemsRoadmap/marketing/posters/poster-1-flagship-showcase.html`

2. **Exporting as High-Resolution PDF / Print:**
   - In your browser, press `Ctrl + P` (or `Cmd + P` on Mac).
   - Set **Destination** to "Save as PDF".
   - Set **Layout** to "Landscape" (for Posters 1, 2, 3) or "Portrait" (for Poster 4).
   - Check **"Background graphics"** under More Settings.
   - Click **Save**.

3. **Exporting as High-DPI PNG for Social Media:**
   - Open Developer Tools in Chrome/Edge (`F12` or `Ctrl + Shift + I`).
   - Press `Ctrl + Shift + P`, type `Capture full size screenshot` or `Capture node screenshot`.
   - Your browser will save a pixel-perfect image ready to upload directly to LinkedIn, X, Instagram, or Facebook.
