# Phase 3: Hardware-Accelerated DSP

This phase merges the knowledge of Phase 1 and Phase 2. You will implement deterministic, real-time signal processing modules directly in Verilog hardware, replacing the slower Python/C++ implementations.

## Goals
- **Objective:** Build functional DSP blocks (mixers, NCOs, FIR filters) in RTL.
- **Key Concepts:** Direct Digital Synthesis (DDS), pipelining, mathematical hardware instantiation, fixed-point arithmetic.
- **Resources:** The ZipCPU Blog (zipcpu.com) - a resource for structuring DSP algorithms for FPGA logic.
